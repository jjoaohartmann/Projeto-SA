COMO USAR ESTE PROJETO
══════════════════════

1. ABRIR HOME
   └─ Clique em index.html
   └─ Verá o simulador expresso funcionando

2. CRIAR CLIENTE
   └─ Clique "Criar Conta" (botão amarelo)
   └─ Preencha registro.html
   └─ Clique "Criar Conta e Solicitar Aprovação"

3. FAZER LOGIN (BLOQUEADO)
   └─ Vá para login.html
   └─ Digite email/senha
   └─ Será bloqueado com mensagem clara

4. APROVAR (COMO ADMIN)
   └─ Vá para login-admin.html
   └─ Email: admin@rtvsolar.com
   └─ Senha: admin123
   └─ Vá para admin.html
   └─ Clique "Aprovar" na tabela de clientes

5. FAZER LOGIN (LIBERADO)
   └─ Volte para login.html
   └─ Digite email/senha do cliente
   └─ Dashboard agora está disponível!
