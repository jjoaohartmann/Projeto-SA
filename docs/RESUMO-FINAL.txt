FLUXO COMPLETO
══════════════

1. CLIENTE NOVO
   └─ Acessa index.html
   └─ Clica "Criar Conta"
   └─ Preenche registro.html
   └─ Submete formulário
   └─ Dados salvos em localStorage
   └─ aprovadoAdmin = false
   
2. CLIENTE TENTA LOGIN
   └─ Acessa login.html
   └─ Digita email/senha
   └─ Sistema verifica: aprovadoAdmin === false
   └─ Bloqueado! Mensagem: "Sua conta está sob análise"

3. ADMIN VISUALIZA
   └─ Acessa login-admin.html
   └─ Faz login com credentials admin
   └─ Acessa admin.html
   └─ Vê seção "Aprovações de Clientes"
   └─ Vê tabela de pendentes

4. ADMIN APROVA
   └─ Clica [Aprovar] para o cliente
   └─ aprovadoAdmin = true
   └─ dataAprovacao = data/hora atual
   └─ Cliente movido para tabela aprovados
   └─ Auditoria registrada

5. CLIENTE CONSEGUE LOGIN
   └─ Acessa login.html novamente
   └─ Sistema verifica: aprovadoAdmin === true
   └─ LOGIN ACEITO!
   └─ Redireciona para dashboard.html
   └─ Dashboard liberado e funcional

6. CLIENTE SOLICITA SERVIÇO
   └─ No dashboard, solicita um serviço
   └─ Salvo em servicosAdquiridos[status: aguardando]

7. ADMIN APROVA SERVIÇO
   └─ Vê seção "Aprovação de Serviços"
   └─ Clica [Aprovar]
   └─ servicoAdquiridos[status: aprovado]
   └─ Cliente notificado (futura: por email)
