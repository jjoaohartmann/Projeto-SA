COMO USAR O NOVO SISTEMA
========================

1️⃣ NOVO CLIENTE SE REGISTRA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Passo 1: Acesse a página inicial (index.html)
         └─ Clique em "Criar Conta" (botão amarelo)

Passo 2: Preencha o formulário em registro.html
         ├─ Nome completo
         ├─ E-mail
         ├─ Telefone
         ├─ Endereço
         ├─ CPF/CNPJ
         ├─ Serviço de interesse
         └─ Senha (mín. 6 caracteres)

Passo 3: Clique "Criar Conta e Solicitar Aprovação"
         └─ Mensagem: "Cadastro realizado! Aguardando aprovação"


2️⃣ CLIENTE TENTA FAZER LOGIN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Neste momento, o cliente:
  ❌ NÃO consegue acessar o painel
  ❌ Recebe mensagem: "Sua conta está sob análise"


3️⃣ ADMIN APROVA CLIENTE
━━━━━━━━━━━━━━━━━━━━━━━━
Passo 1: Acesse login-admin.html
         ├─ E-mail: admin@rtvsolar.com
         └─ Senha: admin123

Passo 2: Você está no admin.html
         └─ Procure a seção "APROVAÇÕES DE CLIENTES"

Passo 3: Veja a tabela "Clientes Aguardando Aprovação"
         ├─ Nome do cliente
         ├─ E-mail
         ├─ Serviço de interesse
         ├─ Data de cadastro
         └─ Botões: [Aprovar] [Rejeitar]

Passo 4: Clique no botão [Aprovar]
         └─ Confirmação: "Cliente XX aprovado com sucesso!"


4️⃣ CLIENTE AGORA TEM ACESSO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Passo 1: Volte to login.html
Passo 2: Faça login com e-mail e senha
Passo 3: ✅ Acesso ao dashboard.html LIBERADO!


➕ O QUE MAIS FOI IMPLEMENTADO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PARA O ADMIN:
  ✓ Edição de métricas em tempo real
    - Clientes Pendentes
    - Clientes Aprovados
    - Total geral
  
  ✓ Seção de "Aprovação de Serviços"
    - Clientes podem solicitar serviços após aprovação
    - Admin aprova os serviços solicitados
  
  ✓ Sistema de Auditoria
    - Todas as ações registradas
    - Motivo de rejeição pode ser adicionado


PARA O CLIENTE:
  ✓ Se não aprovado:
    - Acesso negado ao dashboard
    - Mensagem clara e amigável
  
  ✓ Se aprovado:
    - Acesso completo ao painel
    - Pode solicitar serviços
    - Pode abrir chamados


NO HOME (index.html):
  ✓ Simulador Expresso CORRIGIDO
    - Digite um valor de conta (ex: 500)
    - Veja a economia calculada em tempo real
    - Responsivo em mobile

💡 DICAS IMPORTANTES
━━━━━━━━━━━━━━━━━━

▪ Os dados são salvos no localStorage do navegador
▪ Se limpar cache/cookies, perde os dados
▪ Para desenvolvimento, use DevTools (F12) → Application → localStorage
▪ O admin padrão é: admin@rtvsolar.com / admin123
▪ Para resetar tudo: F12 → Console → localStorage.clear() → Refresh

❓ PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━

Problema: Cliente criado mas não aparece na tabela do admin
Solução: Limpe o cache (Ctrl+Shift+Delete) e tente novamente

Problema: Login bloqueado mesmo após aprovar
Solução: Verifique se salvou corretamente, tente logout completo

Problema: Simulador não calcula
Solução: Verifique se digitou números, não letras

Problema: Página fica em branco
Solução: Verifique console (F12) por erros JavaScript
