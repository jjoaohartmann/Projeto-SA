  • 📍 URL Direto → admin-clientes.html

⚙️ Funcionalidades

✓ Visualizar Clientes
Veja todos os clientes cadastrados em uma tabela com:

  • Nome e Email
  • CPF
  • Status (Aprovado, Pendente, Rejeitado)
  • Data de Cadastro
📊 Filtrar por Status
  • 🟢 Aprovados - clientes aprovados
  • 🟠 Pendentes - aguardando aprovação
  • 🔴 Rejeitados - rejeitados
📈 Estatísticas
  • Total de Clientes
  • Quantos Aprovados
  • Quantos Pendentes
  • Quantos Rejeitados
🗑️ Excluir Cliente
  • Clique no ícone de lixo na coluna de ações
  • Confirme a exclusão
  • Cliente será removido do sistema

🐛 Debug / Problemas

Se algo não funcionar, abra o console do navegador (F12) e procure por:

✓ Logs Verdes = Tudo funcionando
⚠️ Logs Amarelos = Avisos
✗ Logs Vermelhos = Erros

Se vir "AdminClientesAPI não carregada", recarregue a página.
