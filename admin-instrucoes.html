📖 Instruções de Acesso Admin

Como acessar a Gestão de Clientes no site

🔧 Opção 1: Via Menu Lateral

Quando você está autenticado como ADMIN, um link aparece automaticamente no menu lateral de qualquer página:

🔧 Gestão de Clientes

Clique neste link para gerenciar todos os clientes cadastrados

✓ O link aparece em todas as páginas quando você é admin
✓ Está localizado no final do menu lateral
✓ Tem cor amarela para destaque

🎯 Opção 2: Acessar Diretamente

Você também pode acessar direto pelo URL:

admin-clientes.html
➜ Acessar Gestão de Clientes

⚙️ Funcionalidades Disponíveis

👥 Visualizar Clientes

Ver lista completa de todos os clientes cadastrados com nome, email, CPF e status

📊 Filtrar por Status

Filtrar clientes por: Aprovados, Pendentes ou Rejeitados

✓ Estatísticas

Ver métricas rápidas: total, aprovados, pendentes, rejeitados

🗑️ Excluir Cliente

Remover um cliente do sistema com confirmação

🎨 Cores de Status

✓ Aprovado

Cliente foi aprovado pelo admin

⏱ Pendente

Aguardando aprovação do admin

✗ Rejeitado

Solicitação foi rejeitada
